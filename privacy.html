NPGT Regional Jatim 2026

Kebijakan Privasi

Terakhir diperbarui: 11 Oktober 2026

Kebijakan ini menjelaskan bagaimana aplikasi NPGT Regional Jatim 2026 (“Aplikasi”) menangani informasi saat Anda menggunakan dashboard peta dan alat rekap Excel. Dengan menggunakan Aplikasi, Anda memahami praktik yang dijelaskan di bawah ini.

Informasi yang diproses

  • Akun aplikasi: alamat email dan informasi autentikasi yang diperlukan untuk masuk dan mengelola akun. Login aplikasi disediakan oleh Supabase.
  • Akun Google: jika Anda menghubungkan Google Drive, Aplikasi menerima alamat email Google untuk menampilkan akun yang tersambung serta token akses sementara untuk menjalankan permintaan Drive yang Anda minta.
  • File dan hasil: ZIP shapefile, hasil Excel, serta nama dan informasi file yang Anda pilih untuk disimpan. Aplikasi membuat folder “Analisis Penggunaan Tanah” di Google Drive Anda. Pada halaman Tabel, ZIP yang berhasil dibaca disimpan ke Drive; hasil Excel disimpan jika Anda menekan tombol simpan.
  • Preferensi lokal: tema tampilan dan, pada alat Tabel, pengaturan tahun dapat disimpan di penyimpanan browser Anda.

Pemrosesan dan penyimpanan file

Pemrosesan shapefile, PDF, dan pembuatan Excel berlangsung di browser pada perangkat Anda. Aplikasi tidak mengirim isi file ke server aplikasi untuk dianalisis. Jika Anda menghubungkan Drive dan meminta penyimpanan, file dikirim langsung melalui Google Drive API ke Drive akun Google yang Anda pilih. File memakai kuota Drive akun tersebut.

Untuk pengguna yang masuk ke akun aplikasi, file yang disimpan sebelum fitur Drive tersedia mungkin masih berada di penyimpanan Supabase. File lama tersebut dapat dikelola dari daftar “File Saya” di Aplikasi. File baru menggunakan Google Drive setelah Drive dihubungkan. Mode Trial tidak menyimpan file ke akun.

Akses Google Drive

Aplikasi meminta izin Google drive.file untuk membuat, melihat, mengunduh, dan menghapus file yang dibuat Aplikasi di foldernya. Aplikasi juga meminta izin membaca alamat email akun Google yang Anda pilih. Aplikasi tidak meminta akses menyeluruh untuk membaca semua file di Drive. Token akses digunakan sementara di halaman dan tidak disimpan di database Aplikasi.

Data Google Drive digunakan hanya untuk menyediakan fitur penyimpanan, daftar, buka, dan hapus file yang diminta pengguna. Data tersebut tidak dijual atau digunakan untuk iklan. Aplikasi menggunakan dan mentransfer data Google sesuai Kebijakan Data Pengguna Layanan Google API, termasuk persyaratan Limited Use. Penggunaan Google juga tunduk pada kebijakan Google.

Penyedia layanan pihak ketiga

Aplikasi menggunakan Supabase untuk autentikasi dan data file lama; Google untuk autentikasi izin serta penyimpanan Drive; GitHub Pages untuk penyajian situs; dan penyedia eksternal seperti Google Fonts, CDN, serta layanan peta ArcGIS untuk memuat aset dan peta. Permintaan jaringan ke penyedia tersebut dapat menerima informasi teknis standar seperti alamat IP, jenis browser, dan waktu permintaan sesuai kebijakan masing-masing penyedia.

Penyimpanan, penghapusan, dan keamanan

File Drive tetap berada di akun Google Anda sampai Anda menghapusnya. Anda dapat menghapus file melalui “File Saya” atau Google Drive. Anda dapat mencabut izin Aplikasi kapan saja melalui pengaturan keamanan akun Google. File lama Supabase dapat dihapus melalui “File Saya”. Data akun aplikasi diproses selama akun digunakan; untuk permintaan penutupan atau penghapusan akun, gunakan alamat dukungan yang tercantum pada layar persetujuan OAuth aplikasi.

Aplikasi membatasi akses Drive menggunakan izin yang diperlukan untuk fitur tersebut dan tidak menyimpan token akses Drive secara persisten. Tidak ada sistem yang dapat menjamin keamanan absolut; lindungi perangkat serta akun Google dan aplikasi Anda.

Privasi anak dan perubahan kebijakan

Aplikasi adalah alat kerja pengolahan data, bukan layanan yang ditujukan kepada anak-anak. Kebijakan ini dapat diperbarui ketika fitur atau kewajiban yang berlaku berubah. Versi terbaru akan dipublikasikan di halaman ini beserta tanggal pembaruannya.

Kontak

Untuk pertanyaan atau permintaan terkait privasi, hubungi pengelola melalui alamat dukungan yang tercantum pada layar persetujuan OAuth aplikasi.
